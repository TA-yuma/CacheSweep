白名单 / 黑名单

列表中打开开关的项目会被扫描和清理（白名单）；关闭的项目会被忽略（黑名单），体积不再统计，也不会出现在体检结果里。设置会保存在 %APPDATA%\CacheSweep\preferences.json。

添加自定义缓存位置

只有位于安全白名单内的路径才会被接受，其它路径会被明确拒绝并说明原因。

支持 %LOCALAPPDATA% / %APPDATA% / %TEMP% 等环境变量

插件

按需安装清理模块。未安装的插件不会被扫描，也不会占用资源。

启动与运行

开启后登录 Windows 时自动在托盘启动 CacheSweep。

自动清理

只清理可再生的缓存（图片、视频、临时文件），不碰你的文档

仅缓存（图片 / 视频 / 临时文件）

浏览器图片与视频缓存、缩略图缓存、DirectX 着色器缓存、临时文件、崩溃转储。不会清理回收站、开发者缓存，也不会碰任何文档。

安全说明

三道防线，任何一道不通过就不会删除。

安全：删了会自动重建，可一键清理
需确认：会重新下载或首次启动变慢，需要你勾选
高风险：可能含你要找的数据，必须单独确认
永远不会碰：文档、桌面、下载、浏览器密码、系统文件

日志与数据

所有清理操作都会写入审计日志。

关于

CacheSweep 是一款基于 MIT 开源协议的 Windows 磁盘体检与安全清理工具，默认只读、删除进回收站，以普通用户权限运行，无需管理员提权。 磁盘体检与占用分析：扫描各磁盘占用，识别文件夹内容类型，查看软件存储占用，支持列表、卡片、紧凑三种视图。 黑白名单规则管理：可手动添加缓存规则、配置风险分级，支持一键清理，红色高风险项清理时弹出警告。 四层颜色安全分级：绿色安全、黄色需确认、红色高风险、灰色禁止触碰。 定向清理插件：浏览器、微信、QQ、游戏缓存、显卡缓存、开发者缓存专项清理。 国际化与界面自定义：中英俄三种语言，可调字体大小、字体样式、点击反馈强度。 个性化设置：橙、青、灰三套主题，开机自启、最小化悬浮球、定时自动清理。 日志与数据记录：记录每次清理操作，可随时查看历史记录。 开发者：君臨天下
