白名单 / 黑名单

列表中打开开关的项目会被扫描和清理（白名单）；关闭的项目会被忽略（黑名单）， 体积不再统计，也不会出现在体检结果里。设置会保存在 %APPDATA%\CacheSweep\preferences.json。

添加自定义缓存位置

只有位于安全白名单内的路径才会被接受，其它路径会被明确拒绝并说明原因。

支持 %LOCALAPPDATA% / %APPDATA% / %TEMP% 等环境变量

外观主题

三套主题各配一种水果意象：赤橙暖橙、青蔗钢灰、碧提青提。桌面程序中「碧提」会让窗口真正半透明，露出桌面壁纸。

也可以在右上角用图标快速切换。

安全说明

三道防线，任何一道不通过就不会删除。

安全：删了会自动重建，可一键清理
需确认：会重新下载或首次启动变慢，需要你勾选
高风险：可能含你要找的数据，必须单独确认
永远不会碰：文档、桌面、下载、浏览器密码、系统文件

日志与数据

所有清理操作都会写入审计日志。
