快速上手

  1. 下载并解压

    下载 CacheSweep-win-x64.zip，解压到任意位置。

  2. 运行

    双击 CacheSweep.exe，程序会在托盘运行并自动打开界面。

  3. 体检

    点击「开始体检」，几秒钟即可看到本机所有缓存占用。

  4. 清理

    勾选想清理的项，点「预览清理」确认无误后再「执行清理」。文件默认进回收站。

常见问题

会误删我的重要文件吗？

不会。三道防线 + 默认进回收站 + 预览确认。CacheSweep 只清理明确的缓存目录，永远不碰文档、桌面、下载区。

它会联网上传数据吗？

不会。它在本地运行，只在你主动点击「检查更新」时才访问 GitHub。所有扫描和清理都在你自己的电脑上完成。

为什么是开源的？

安全工具必须透明。代码公开在 GitHub，任何人都能审查它不会做任何坏事。

需要管理员权限吗？

不需要。它以普通用户权限运行，只清理当前用户能访问的缓存。
